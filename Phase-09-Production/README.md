# Phase 09 — Production

Phase này biến debugging từ đoán mò thành quy trình dựa trên evidence.

```text
Symptom → Evidence → Hypotheses → Measure → Root Cause → Fix → Prevention
```

Phạm vi gồm crash/symbolication, hang, leak, pressure, CPU, scrolling, launch, network, energy, background execution, release-only/device-specific bug, concurrency incident và observability. Mỗi case phải chỉ rõ công cụ và tín hiệu cần quan sát.

Roadmap chi tiết nằm trong [SUMMARY](../SUMMARY.md).
