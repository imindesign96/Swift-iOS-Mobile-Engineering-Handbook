# Phase 10 — Mobile System Design

Phase này thiết kế trong ràng buộc của thiết bị: memory, battery, unstable network, storage, lifecycle, background limits và offline.

Mỗi case dùng cùng framework:

```text
Requirements → Constraints → Data/State → Architecture
→ Network/Persistence/Concurrency → Failure/Security/Performance
→ Observability/Testing → Trade-offs
```

Case bắt buộc gồm Image Loader, Feed, Chat, Download Manager, Offline-first, Authentication, Search, Analytics SDK, Feature Flags, large-scale modularization và UIKit → SwiftUI migration.

Roadmap chi tiết nằm trong [SUMMARY](../SUMMARY.md).
