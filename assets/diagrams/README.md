# Diagrams

Thư mục này chỉ dành cho sơ đồ không thể diễn đạt rõ bằng ASCII hoặc Mermaid.

Quy ước:

- ưu tiên ASCII cho flow ngắn;
- dùng Mermaid cho sequence, state, class và dependency graph;
- chỉ thêm ảnh khi hình ảnh thực sự mang thông tin;
- tên file dùng ASCII, mô tả thay thế phải nói được ý nghĩa của hình;
- sơ đồ phải được liên kết từ chapter sở hữu nó, không tồn tại như tài sản trang trí.
