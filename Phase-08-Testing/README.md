# Phase 08 — Testing

Phase này dùng test để tạo confidence ở đúng boundary, không chạy theo coverage phần trăm.

```text
Fast feedback: Unit
Boundary confidence: Integration
Critical user flows: UI
```

Người học phải phân biệt Mock/Stub/Fake/Spy, test async code mà không dựa vào sleep, cô lập networking, giảm flaky test và thiết kế code testable bằng dependency injection.

Roadmap chi tiết nằm trong [SUMMARY](../SUMMARY.md).
